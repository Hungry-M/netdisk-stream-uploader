# 发布检查清单

这份清单是 **1.0.0 的门槛**。功能写完不等于能用——安装、真实网盘、续传、卸载
这四段只要有一段没在真机上走过，就不该打 1.0.0。

在实机上逐项打勾，任何一项失败就停在 0.x，修完重来。

---

## 一、构建与安装

- [ ] `python -m pytest -q` 全绿（退出码 0，不是"看着全过"）
- [ ] `scripts/build_release.ps1` 成功，`dist/` 下有 `StreamPack-*` 和 `StreamPack-Setup-*.exe`
- [ ] 双击 `StreamPack-Setup-*.exe`：装到 `%LOCALAPPDATA%\Programs\StreamPack`
- [ ] 开始菜单出现快捷方式，图标不是白纸
- [ ] 「设置 → 应用」里能看到 StreamPack，卸载命令指向安装目录

## 二、真实网盘（必须用真账号）

先用一条命令生成固定内容的测试数据（同一 seed 字节相同，方便事后核对 SHA-256）：

```powershell
python scripts/make_test_data.py            # 默认生成到 D:\streampack-test\data
```

它会打印一整套可直接复制的上传命令（连续流 / 自包含 / 超限检查 / 跨卷 / 查找）。

- [ ] 首次运行填 AppKey / SecretKey / 应用名，授权码流程走通
- [ ] 小文件（< 分卷大小）上传成功
- [ ] 大文件（> 分卷大小）上传成功，分卷数正确
- [ ] 网盘里该应用目录下能看到全部分卷
- [ ] 下载回来拼接 → 解压 → 内容 SHA-256 与源一致

## 三、两种布局

- [ ] `--layout continuous`：分卷拼接后可解压
- [ ] `--layout self-contained`：随便挑一卷，7-Zip 直接打开，内容完整
- [ ] `--pack-by folder`：同一个顶层文件夹尽量落在同一卷（检查索引）
- [ ] 单文件超过分卷时，**上传开始前**就报错并列出文件名
- [ ] `find <文件名>` 能给出正确的卷号

## 四、续传与异常

- [ ] 上传中途 Ctrl+C，`list` 显示 `interrupted`
- [ ] `resume <id>` 从断点继续，最终完成
- [ ] 改动源文件后再 `resume`：给出差异并中止（不是继续传错误数据）
- [ ] 加密任务：口令错误时 `resume` 被拒绝，不是白跑一遍
- [ ] 加密任务：7-Zip 输入口令能正常解压

## 五、界面

- [ ] 新建任务：选文件夹 / 选文件 / 拖放三种方式都能建任务
- [ ] 设置对话框：改语言、主题、应用名后重启生效
- [ ] 查找文件（Ctrl+F）能定位到卷
- [ ] 未签名时「未知发布者」提示符合文档描述
- [ ] 签名后本机不再提示，且 `trust-sign.ps1 -RemoveCert` 能撤销

## 六、卸载

- [ ] 「设置 → 应用」卸载，或运行安装目录的 `uninstall.cmd`
- [ ] 安装目录、快捷方式、卸载项都消失
- [ ] 用户数据默认保留；`-PurgeData` 能一并删除
- [ ] 卸载后重装，配置和任务记录还在（默认不删数据）
